## 🎯 Ключевые выводы

1. **QAZRem покрывает ~30% функционала ROApp** — есть ядро (заказы, запчасти, базовые финансы), но отсутствуют целые модули
2. **Главные пробелы:** кассы со сплитованием платежей, складские операции, контакты, отчёты
3. **Архитектура требует рефакторинга:** монолитные страницы, нет слоя бизнес-логики, дублирование кода
4. **Приоритет:** сначала доработать заказы (фильтры, поля, изображения), затем кассы и оплату, затем исправить баги с услугами/запчастями, затем контакты и склад

## 📏 Правила написания кода

| Правило | Описание |
|---------|----------|
| **Максимум 200–250 строк на файл** | Если компонент/роутер/страница превышает лимит — выноси логику в отдельный файл |
| **Куда выносить** | Бэкенд: роутер → сервис → репозиторий. Фронтенд: страница → компонент → хук/утилита |
| **Переиспользуй компоненты** | Не пиши таблицу/фильтры/модалку с нуля для каждой страницы — бери готовый общий компонент. Это ускоряет разработку и делает UI консистентным |
| **Пример** | `DashboardPage.tsx` (500 строк) → разбить на `OrderStats`, `OrderTable`, `OrderBoard`, `QuickFilters`, `OrderSummary` |

### Общие компоненты — всегда используй их, не дублируй

| Компонент | Где использовать |
|-----------|-----------------|
| `DataTable<T>` | Заказы, контакты, склад, отчёты, кассы — везде где таблица |
| `FilterBar` | Заказы, контакты, склад — везде где фильтры |
| `KanbanBoard<T>` | Заказы — канбан-доска |
| `StatusBadge` | Заказы, контакты — бейдж статуса |
| `Modal` / `ConfirmDialog` | Любая форма создания/редактирования, подтверждение удаления |
| `QuickChips` | Быстрые фильтры по брендам/мастерам |

> 🔴 **Не создавай `ContactsTable`, `PartsTable`, `OrdersTable`, `FinanceTable`** — это одна и та же таблица с разными колонками. Используй `DataTable<T>` и передавай `columns` и `data`.

### Файлы, требующие разбивки (техдолг)

| Файл | Строк | План разбивки |
|------|-------|--------------|
| `DashboardPage.tsx` | >500 | → `components/orders/` (6 компонентов) |
| `SettingsPage.tsx` | >800 | → `pages/settings/` (7 вкладок) |
| `CreateOrderPage.tsx` | >400 | → `components/orders/OrderForm.tsx` |
| `api.ts` | >400 | → `api/orders.ts`, `api/finance.ts`, `api/accounts.ts` и т.д. |
| `orders.ts` (бэкенд) | >600 | → `services/order.service.ts` + `repositories/order.repo.ts` |
