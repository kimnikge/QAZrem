## 🐛 3.3 — Исправление багов: услуги и запчасти в заказе ✅ **ГОТОВО**

> Детали: см. `сравнительный-анализ-roapp-vs-qazrem.md` → раздел «4. Склады → 🐛 Найдены баги»

### Баг 1: Услуги не добавляются в заказ

Таблица `order_services` есть, но не используется.

**Бэкенд:**
1. `GET /orders/:id` — добавить JOIN `order_services`
2. `POST /orders/:id/services` — новый эндпоинт
3. `DELETE /orders/:id/services/:sid` — новый эндпоинт
4. `POST /orders` — принимать `services` при создании

**Фронтенд:**
- Тип `OrderDetail.services`
- API-методы `assignServiceToOrder`, `deleteOrderService`
- UI: выбор услуг на `CreateOrderPage` + отображение на `OrderDetailPage`

### Баг 2: Запчасти исчезают при редактировании

`OrderDetailPage.tsx` — показывать `order.parts` и `order.services` всегда, а не только при `!editing`.
