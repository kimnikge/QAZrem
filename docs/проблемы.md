### 3. ✅ Добавить `requireRole` на роут `/users` — **ВЫПОЛНЕНО**

**Где:** `backend/src/routes/users.ts`

`requireAuth` стоит на уровне роутера, `requireRole` добавлены на каждый эндпоинт:

- `GET /users` — только `admin`
- `GET /users/masters` — `admin` и `reception`
- `POST /users` — только `admin`
- `PATCH /users/:id` — только `admin`

---

### 4. ✅ Перенести JWT из localStorage в httpOnly cookie — **ВЫПОЛНЕНО (гибрид)**

**Где:** `frontend/src/context/AuthContext.tsx`, `frontend/src/api.ts`, `backend/src/routes/auth.ts`, `backend/src/middleware/auth.ts`

**Реализован гибридный подход:**
- **Бэкенд**: `cookie-parser` + `res.cookie('token', ..., { httpOnly: true })` при логине. Middleware `requireAuth` читает токен: сначала из cookie, затем из Bearer-заголовка (обратная совместимость).
- **Фронтенд**: `localStorage` → `sessionStorage` (токен живёт только пока открыта вкладка). API продолжает отправлять Bearer-заголовок.

---

**Где:** `backend/src/routes/health.ts`

**Реализован вариант А:** Убрана информация о БД и timestamp, оставлено только `{ status: 'ok' }`.

### 14. Настроить корректный CORS для production

**Где:** `backend/src/config/env.ts` и `backend/src/app.ts`

```
API_CORS_ORIGIN=https://yourdomain.com
```
