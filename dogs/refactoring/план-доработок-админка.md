## 🔧 API-СЛОЙ

### 3. `api/warehouse.ts` — NEW (~120 строк)

Все новые эндпоинты в одном файле. Короткие функции, каждая ≤10 строк.

```
getCategories() → GET /warehouse/categories
getCategoryTree() → GET /warehouse/categories/tree
createCategory(data) → POST /warehouse/categories
updateCategory(id, data) → PATCH /warehouse/categories/:id
deleteCategory(id) → DELETE /warehouse/categories/:id
getCategoryAttributes(catId) → GET /warehouse/categories/:id/attributes
createCategoryAttribute(catId, data) → POST /warehouse/categories/:id/attributes
updateCategoryAttribute(attrId, data) → PATCH /warehouse/categories/attributes/:attrId
deleteCategoryAttribute(attrId) → DELETE /warehouse/categories/attributes/:attrId

getInventorySheets() → GET /warehouse/inventory
createInventorySheet(data) → POST /warehouse/inventory
getInventorySheet(id) → GET /warehouse/inventory/:id
updateSheetStatus(id, status) → PATCH /warehouse/inventory/:id/status
updateInventoryItem(itemId, data) → PATCH /warehouse/inventory/items/:itemId

getEquipment(masterId?) → GET /warehouse/inventory/equipment
createEquipment(data) → POST /warehouse/inventory/equipment
updateEquipment(id, data) → PATCH /warehouse/inventory/equipment/:id
deleteEquipment(id) → DELETE /warehouse/inventory/equipment/:id

getStockReport(categoryId?) → GET /warehouse/reports/stock
getMovementReport(filters) → GET /warehouse/reports/movements
getTopParts(limit?) → GET /warehouse/reports/top-parts
getStaleParts(days?) → GET /warehouse/reports/stale
getSupplierReport() → GET /warehouse/reports/by-supplier
getCategoryReport() → GET /warehouse/reports/by-category
```
